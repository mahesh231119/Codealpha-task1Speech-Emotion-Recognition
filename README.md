📌 Project Title

Speech Emotion Recognition – Exploratory Data Analysis

📖 Overview

This project focuses on analyzing audio data to understand patterns in human emotions such as happy, sad, angry, and neutral using exploratory data analysis (EDA).

🎯 Objective
Analyze audio dataset
Extract meaningful features
Visualize emotion distribution
Identify patterns in speech signals
🛠️ Tech Stack
Python
NumPy
Matplotlib / Seaborn
Librosa
⚙️ Process
1. Data Loading
Load audio files
Label emotions
2. Feature Extraction
Extract MFCC features
Analyze waveform
3. Data Visualization
Emotion distribution
Wave plots
Spectrogram analysis
📊 Key Insights
Different emotions show distinct audio patterns
MFCC features help differentiate emotions
Data imbalance observed in some classes
🚀 Outcome
Strong understanding of audio data
Prepared dataset for model training
Identified key patterns for classification
